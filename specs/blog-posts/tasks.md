## Phase 1: Database & Models

### Task 1: Create Posts Database Schema

**User Story**: Infrastructure
**Type**: Database
**Dependencies**: None

**Description:**
Define the Drizzle ORM schema for `posts`, `postsToArtworks`, and `postsToCollections` tables. Follow the existing patterns in `schema.artworks.ts` (auto-increment ID, unique slug, `publishedAt` timestamp, `createdAt`/`updatedAt`, `locale`, cascade deletes on junction tables).

**Files to Create/Modify:**

- `src/database/schema.posts.ts` - New file: define `posts`, `postsToArtworks`, `postsToCollections` tables with relations
- `src/database/index.ts` - Add exports for new schema (if schema files are re-exported here)

**Acceptance Criteria:**

- [ ] `posts` table has: id, slug (unique), title, body, excerpt, postType, coverImageUrl, publishedAt, scheduledAt, locale, createdAt, updatedAt
- [ ] `postsToArtworks` junction table with composite PK and cascade deletes
- [ ] `postsToCollections` junction table with composite PK and cascade deletes
- [ ] Drizzle relations defined for posts ↔ artworks and posts ↔ collections
- [ ] Type exports: `SelectPost`, `NewPost` (inferred from schema)

**Validation:**
`npm run typecheck` passes with new schema file.

### Task 3: Create Post Model Layer

**User Story**: US-1, US-2, US-4, US-5
**Type**: Backend
**Dependencies**: Task 2

**Description:**
Create the model/query layer for posts following the existing filter-object pattern in `src/models/artwork.ts`. Implement `findPosts(filters)` for base queries and `findPostsWithRelations(filters)` for loading linked artworks and collections via parallel Promise.all.

**Files to Create/Modify:**

- `src/models/post.ts` - New file: `PostFilters` interface, `findPosts()`, `findPostsWithRelations()`, type interfaces (`PostWithRelations`)

**Acceptance Criteria:**

- [ ] `PostFilters` supports: id, slug, published, postType, artworkId, collectionId, locale
- [ ] `findPosts(filters)` returns array of posts matching filters
- [ ] `findPostsWithRelations(filters)` returns posts with linked artworks (id, slug, title, defaultImageUrl) and collections (id, slug, name)
- [ ] Published filter handles both `publishedAt` and `scheduledAt` (request-time evaluation)
- [ ] Scheduled post promotion: when a scheduled post's time has passed, sets `publishedAt = scheduledAt`
- [ ] Results ordered by `publishedAt` descending (newest first)

**Validation:**
`npm run typecheck` passes. Model functions can be called from server actions in subsequent tasks.

**Dependencies**: Task 3

**Description:**

**Files to Create/Modify:**

**Acceptance Criteria:**

- [ ] `createPostAdmin(data)` creates post with slug generation, handles artworkIds and collectionIds
- [ ] `updatePostAdmin(id, data)` updates post fields and relationships (delete-all + re-insert for junction tables)

- [ ] `getAllPostsAdmin()` returns all posts (including drafts/scheduled) for admin list
- [ ] `getPostBySlugAdmin(slug)` returns post with linked artworks and collections for edit form
- [ ] All actions use `guardAdmin()` at entry
- [ ] All mutations call `revalidatePath()` for `/admin/posts`, `/posts`, affected artwork/collection pages

**Validation:**
